ezcal ハンドブック

構造ファイルを 1 つ渡すだけで、構造最適化からバンド構造・状態密度まで通す。 カットオフも k 点も擬ポテンシャルも、指定しなければ自動で決まります。

engine Quantum ESPRESSO 7.5 python ≥ 3.10 venv ezcalenv312 also SevenNet (MLIP)
このページの読み方

左の「表示」で 基本 に絞ると、はじめての人が必要な 5 章だけになります。 応用 は全オプション・設定ファイル・クラスタ運用・Python API・拡張です。

01

5分で最初の計算

基本

インストールして、Si のバンド構造と状態密度を出すところまで。

1インストール

仮想環境を有効にして、リポジトリを editable で入れます。依存パッケージ（pymatgen・ASE・seekpath・matplotlib・plotly ほか）も一緒に入ります。

$ source /home/tajimamainpc/.venv/ezcalenv312/bin/activate
$ uv pip install -e /home/tajimamainpc/06_claude_code/08_qez
$ ezcal version
ezcal 0.1.0  (python 3.12.3)

Materials Project から構造を取りたいときや、機械学習ポテンシャルを使いたいときは追加で入れます。

$ uv pip install -e '/home/tajimamainpc/06_claude_code/08_qez[all]'   # + mp-api, jupyter
$ uv pip install sevenn                                              # SevenNet (MLIP)
$ uv pip install aiida-vasp                                          # mock-vasp (VASP 再生)

2Quantum ESPRESSO の場所を確認

pw.x は既定で ~/repos/q-e/bin から探します。違う場所にあるなら設定ファイルで変えます（06 章）。まず今の状態を確認しましょう。

$ ezcal engines
engine tasks status qe scf, relax, vc-relax, nscf, bands, dos ready vasp scf, relax, vc-relax, nscf, bands, dos VASP command 'vasp_std' not found … mlip scf, relax, vc-relax ready

VASP は vasp.command が指す実行ファイルを使います。ライセンスが無くても mock-vasp で記録済み計算を再生できます（08 章）。

3構造を用意する

CIF・POSCAR・xyz・pymatgen JSON・QE の入出力ファイルが読めます。Materials Project の ID をそのまま渡すこともできます。

$ ezcal mp mp-149 --out Si.cif --mp-api-key <あなたのキー>
Si -> Si.cif

# 環境変数に入れておけば --mp-api-key は不要
$ export MP_API_KEY=<あなたのキー>

4何が起きるか先に見る

計算を投げる前に、ezcal が自動で決めた値を確認できます。ここで出た擬ポテンシャルは、この時点でダウンロード済みになります。

$ ezcal info Si.cif --band-path
{ "formula": "Si", "natoms": 2, "volume": 40.048, "spacegroup": "Fd-3m", "spacegroup_number": 227 } suggested k-mesh (kspacing=0.25): [9, 9, 9] Si Si.pbe-n-kjpaw_psl.1.0.0.UPF (PAW, Z=4) suggested cutoffs: ecutwfc=44.0 Ry ecutrho=352.0 Ry k-path (131 points): Γ -> X -> U|K -> Γ -> L -> W -> X

5走らせる

auto は初期構造から最後まで一気に通します。セル最適化 → SCF → 密メッシュの NSCF → 状態密度 → バンド構造の順で、電荷密度を使い回します。

$ ezcal auto Si.cif --np 8 --plot both

これだけです。2 原子の Si なら 8 コアで 1 分ほど。結果は ezcal_out/Si_auto/ に入ります。

急いでいるとき

テストや下見なら --ecutwfc 30 --kmesh 6 6 6 --conv-thr 1e-6 のように緩めると数倍速くなります。 本番の数字を出すときは付けないでください（自動値が使われます）。

前段を飛ばす・一部だけ飛ばす

scf→bands

すでに同じ実行ディレクトリで scf が終わっていて、バンドだけ描き直したい場合は --only を付けます（tmp/ に電荷密度が残っている必要があるので、-o と --name で同じ場所を指してください）。auto の途中を抜くには --skip です。

$ ezcal bands Si.cif --only -o ezcal_out --name Si_auto   # scf を再実行しない
$ ezcal auto Si.cif --skip nscf,dos                        # DOS は要らない
$ ezcal auto Si.cif --no-relax                             # 構造最適化しない
$ ezcal auto Si.cif --fixed-cell                           # セルは固定して原子だけ緩和

  • nscf と bands に E が出ないのは正常です。非自己無撞着計算の全エネルギーは物理的に意味を持たないので、あえて表示していません。
  • gap は価電子数から占有バンド数を数えて求めています。スメアリングを使うと QE の EF は絶縁体でも価電子帯上端より下に来るため、「EF を跨ぐバンドがあるか」で判定すると Si すら金属になってしまいます。金属なら 0.000、そしてレポートに「metallic」と明記されます。
  • gap が段によって少し違うのは k 点密度の差です。密メッシュの nscf / bands の値がより正確です。
  • スピン分極計算では M（正味の磁化）と |M|（絶対磁化）の列が自動で増えます。 反強磁性では M ≈ 0、|M| が実際の大きさです。サイトごとの磁気モーメントは report.md と summary.json の site_magnetization に入ります。 nscf と bands は電荷密度を作り直さないので、この 2 列は - になります。

1. k 点

指定しなければ kspacing（既定 0.25 Å⁻¹、2π 込み＝VASP の KSPACING と同じ流儀）から逆格子ベクトル長で決まります。 セルが小さいほどメッシュは密になります。金属は絶縁体より 1.5〜2 倍密にしてください。

$ ezcal scf Si.cif --kmesh 8 8 8      # 直接指定
$ ezcal scf Si.cif --kspacing 0.15    # 間隔で指定（大きなセルでも一貫する）

DOS 用の nscf は自動で scf の 2 倍にします（nscf.kmesh_scale）。

2. カットオフ

擬ポテンシャルのヘッダに書かれた推奨値の、系内の全元素での最大値を使います。 ecutrho は PAW/USPP なら ecutwfc × 8、ノルム保存なら × 4。 どの値が採用されるかは ezcal pseudo fetch で先に確認できます。

$ ezcal pseudo fetch Mg O
element file type Z_val ecutwfc ecutrho Mg Mg.pbe-spnl-kjpaw_psl.1.0.0.UPF PAW 10 58 385 O O.pbe-n-kjpaw_psl.1.0.0.UPF PAW 6 47 323 suggested for this set: ecutwfc=58.0 Ry, ecutrho=464.0 Ry

ecutwfc は 2 元素の最大値 58 Ry。ecutrho は各ファイルの推奨値 (385, 323) より 58 × 8 = 464 のほうが大きいので、そちらが採用されます。

カットオフを下げると答えが変わります

テストで MgO を 58 Ry ではなく 40 Ry で回すと、バンドギャップが 4.49 eV → 5.67 eV とずれました。 速度のために下げるのは下見のときだけにしてください。

3. 占有数とスメアリング

設定使いどころ
smearing + mv（既定）金属。絶縁体でも安全側に動くので既定にしている
fixedギャップがあると分かっている系。EF が VBM に乗るので図が読みやすい
tetrahedraDOS を滑らかにしたいとき。nscf 段では自動でこれを使う

4. 磁性

強磁性

--spin でスピン分極（nspin=2）になります。初期磁化を与えないと全元素 0.3 が入るので、 磁性元素には明示したほうが収束が速くなります。

$ ezcal auto Fe.cif --spin --magmom Fe=0.6 --kmesh 12 12 12 --degauss 0.03

結果表に M（正味の磁化）と |M|（絶対磁化）の列が増え、 DOS はアップ/ダウンが上下に分かれて描かれます。

反強磁性

--afm で元素を副格子に分けます。その元素のサイトを出現順に Ni1, Ni2, Ni1, … とラベル付けし、 +m, -m を交互に与えます。pw.x からは別々の species に見えるので、 対称性も正しく下がります。

$ ezcal auto NiO.cif --afm Ni=2.0 --hubbard-u Ni=6.0
$ ezcal scf Cr.cif --afm Cr                 # 大きさを省くと 0.5 が使われる
$ ezcal scf Cr.cif --magmom Cr=1.0/-1.0     # --afm Cr=1.0 と同じ
$ ezcal scf X.cif --magmom Mn=2/-2/2/-2,O=0  # 4 副格子も書ける
磁気単位胞は自分で用意してください

反強磁性配置を収められる大きさのセルが要ります。NiO なら岩塩型の primitive cell （Ni 1 個）ではなく、AFM-II の菱面体 4 原子セル（Ni 2 + O 2）です。 副格子を指定すると ezcal は自動的に --as-is に切り替え、セルを縮約しません。 サイト数が足りなければその場でエラーになります。

  • +U は元素指定のままで通ります。--hubbard-u Ni=6.0 は U Ni1-3d 6.0 と U Ni2-3d 6.0 の両方に展開されます。 副格子ごとに変えたければ --hubbard-u Ni1=6.0,Ni2=5.0 と書けます。
  • バンド計算も磁気単位胞で行われます。seekpath にも副格子を別 species として渡すため、 磁気ブリルアンゾーンに対応した正しい経路が使われます（例: bcc Cr は AFM にすると bcc の Γ-H-N-P ではなく単純立方の Γ-X-M-R になります）。
  • PDOS は副格子ごとに出ます。反強磁性なら Ni1-d と Ni2-d が上下対称の鏡像になり、 これが秩序が立っている証拠になります。
  • 正味の磁化 M はほぼ 0 になります。意味のある数字は |M|（絶対磁化）と、 レポートに出るサイトごとの磁気モーメントです。
# NiO (AFM-II) + U=6 eV, report.md より step ok E_F (eV) gap (eV) M (uB/cell) abs M (uB/cell) scf yes 15.0130 3.204 0.000 3.586 nscf yes 15.2861 3.063 - - Magnetic moment per site (uB): Ni1 +1.660, Ni2 -1.660, O -0.000, O -0.000

VASP

入力生成（INCAR / POSCAR / KPOINTS / POTCAR）、実行、vasprun.xml と OUTCAR の解析、バンド・DOS・PDOS の抽出まで通っています。 実行ファイルは vasp.command が指すものなら何でもよく、 ライセンスが無くても aiida-vasp の mock-vasp で全経路を動かせます。

mock-vasp で動かす

mock-vasp は INCAR / KPOINTS / POSCAR をパースしてハッシュを取り、 レジストリに一致する計算があればその出力を複製して返す疑似 VASP です。 再生されるのは実際の VASP 出力なので、数字は「その入力に対する本物の VASP の答え」です。

$ uv pip install aiida-vasp          # mock-vasp が入る

$ ezcal scf POSCAR --engine vasp --as-is \
      --set vasp.command=mock-vasp \
      --set vasp.mock.registry=./vasp_mock_registry

$ ezcal vasp registry --registry ./vasp_mock_registry   # 中身を見る
$ ezcal vasp hash ./runs/Si_vasp/00_scf                 # 不一致の調査
┃ entry ┃ hash ┃ │ si-simple/calc-000 │ 32740fbd728a1e9863e75303b43f4616 │ # 実行すると report.md / summary.json に出所が残る [scf] mock-vasp replayed recorded VASP output from …/si-simple/calc-000 (the inputs hash-matched that entry)

記録して配る

実 VASP のあるマシンで計算を記録し、レジストリを配れば、ライセンスの無いマシンでも 同じ入力を ezcal から再生できます。vasp.mock.vasp_cmd に実 VASP を書いておくと、 未登録の入力は実行して自動で登録します。

$ ezcal vasp record ./runs/Si_vasp/00_scf --name si-scf/calc-000 --registry ./reg
ハッシュはパース後の値で取られます

ENCUT = 200(整数) と ENCUT = 200.0(実数) は別物として扱われます。 ezcal が INCAR と KPOINTS を pymatgen 任せにせず自前で書いているのはこのためです。 記録済みの入力を厳密に再現したいときは vasp.incar_mode: replace を使ってください。

実 VASP で動かす

  • 1. POTCAR ライブラリを用意し pmg config -p <PSP dir> <target>、vasp.potcar_dir を設定
  • 2. vasp.command に MPI 実行ファイルを設定。これだけです
  • POTCAR は勝手に捏造しません。potcar_mode: auto は、ライブラリがあればそこから生成し、 無くてコマンドが mock のときだけ「これは擬ポテンシャルではない」と明記したプレースホルダを書きます。 実 VASP でライブラリが無ければエラーで止まります。

# ezcal/engines/mycode.py
from ezcal.engines.base import CalcResult, Engine

class MyEngine(Engine):
    name = "mycode"
    supported = ("scf", "relax")          # 対応外のタスクは自動で拒否される

    def check(self):                       # 実行前チェック
        return []                          # 問題があれば文字列のリスト

    def run(self, structure, task, workdir, prev=None, **kwargs):
        # 1. 入力を書く
        # 2. self.scheduler.execute(Stage(...))  ← local/qsub の違いは意識しない
        # 3. 出力を解析して CalcResult に詰める
        return CalcResult(task=task, engine=self.name, workdir=workdir, ok=True)

# ezcal/engines/__init__.py に 1 行
register("mycode", lambda config, scheduler: MyEngine(config, scheduler))

ezcal は QE の既知のエラー（対角化の破綻、SCF 不収束、G ベクトル不足など）を見分けて、 次に試すことを hint: として表示します。エラー本文もレポートに残ります。

結果がおかしいと感じたら

  • まずカットオフと k 点を上げて再現するか見る。ギャップや格子定数のずれはほぼこれです。自動値を使えば安全側です。
  • 金属なのにギャップが出る／絶縁体なのに金属と出る。価電子数が想定と違う可能性があります。summary.json の nelec と nbnd を確認してください。
  • 磁性が消える。--magmom の初期値を大きめ（0.6〜1.0）にし、k 点を増やしてください。 反強磁性が強磁性に落ちてしまう場合は --afm Ni=2.0 のように初期値を大きく取り、 --set dft.mixing_beta=0.3 で混合を弱めます。
  • 反強磁性なのに |M| が 0 になる。秩序が壊れています。まず scf.in の ntyp が副格子の数だけあるか、starting_magnetization の符号が 分かれているかを確認してください。
  • vc-relax が終わらない。relax.press_conv_thr（既定 0.5 kbar）は厳しめです。金属で k 点が粗いと圧力が振動します。
  • QE の生の出力が見たい。各段のディレクトリに *.in と *.out がそのまま残っています。ezcal は何も隠しません。

再現する

実行ディレクトリの qe_config.used.yaml には、自動決定された値も含めて実際に効いた設定が全部入っています。

$ ezcal auto Si.cif -c ezcal_out/Si_auto/qe_config.used.yaml

原子電荷は2通り出ます

手法出どころ性格
Löwdinprojwfc.x の出力に元から入っている（追加計算ゼロ） 軌道分解（s/p/d/f）と原子ごとの磁気モーメントも同時に得られる。基底への射影なので定義依存が強め
Bader密度をグリッド上で原子の basin に分割（外部バイナリ不要の内蔵実装） 基底に依らない。グリッド由来の不確かさが 0.01〜0.05 e 程度
# MgO の properties.md より # site element Löwdin charge (e) Bader charge (e) Bader volume (Å³) 1 Mg Mg 1.524 1.683 4.80 2 O O -1.358 -1.683 13.88

値が違うのは定義が違うからです。系どうしを比べるときは、必ず同じ手法どうしで比べてください。 Bader の合計はゼロになり、basin 体積の和はセル体積に一致します（内部の検算に入れてあります）。

どの密度を使うか

--charge-kindspp.x用途
density（既定）plot_num=0 擬電荷密度。積分が価電子数と厳密に一致し、Bader が安定
spin6ρ↑−ρ↓。nspin=2 なら自動で追加される
ae_valence / ae_total17 / 21 PAW の全電子密度。scf の FFT グリッドでは粗すぎて破綻します
potential11bare + Hartree ポテンシャル
全電子密度（17 / 21）は grid が足りないと壊れます

QE のドキュメントにも「非常に密な実空間グリッドが必要」と書かれています。実際 NiO を 75³ グリッドで試すと、plot_num=21 は積分が 72 e のはずが 115 e になり、 等価な 2 つの Ni に別々の電荷が出ました。ezcal は積分値を価電子数と突き合わせて 自動で警告しますので、警告が出たら density に戻すか ecutrho を上げてください。

物理量のまとめ（properties.md）

バンドギャップ（金属なら 0 と明記）・フェルミ準位・VBM/CBM・全磁化と絶対磁化・ 原子ごとの磁気モーメントと電荷が 1 ページにまとまります。どのステップが出した値かも書かれます。

  • 原子ごとの磁気モーメントは 2 通り出ます。pw.x の球積分値と Löwdin の 射影値で、独立な見積もりなので食い違いが大きければ収束を疑う材料になります （AFM NiO では ±1.388 と ±1.330 でよく一致）。
  • 3D 等値面は両方の副格子が同時に見える唯一の図です。2D 断面は charge.slice_fraction の平面しか通らないので、反強磁性体では片方しか映らないことがあります。

結果の読み方

  • 格子定数と体積弾性率は実験と数 % で合うはずです。ここが大きくずれていたら、 擬ポテンシャル・カットオフ・k 点のどれかがおかしいと考えてください。
  • バンドギャップは実験より 5 割ほど小さく出ます。これは PBE の既知の性質で、 バグではありません。MP も PBE 系なので MP とは MAE 0.15 eV でほぼ一致します。 インストールの健全性はこちらで判断してください。
  • MP が別相に緩和した系は a / c の比較から自動で除外されます （Fe→Fmmm, BaTiO3→I4/mcm, CoO→R-3m など）。体積・密度・ギャップは比較を続けます。
  • パリティ図は実験用と MP 用の 2 枚出ます。MP の図はギャップまで対角線上に乗り （外れる 2 点は MP が +U を使う NiO と MnO）、実験の図でギャップだけが下振れするのと 対照的です。この 2 枚を見比べるのが、実装の健全性を判断する一番早い方法です。 MP 用の図は --mp-api-key を渡したときだけ作られます。
  • NiO / MnO / CoO は反強磁性セルで計算します。+U を付けていないので ギャップは実験より大幅に小さく出ます。
  • 凝集エネルギー・生成エネルギーは含めていません。孤立原子や O₂ の基準計算と アニオン補正が必要で、インストール確認とは別の作業だからです。

用語ミニ辞典

基本

オプション名に出てくる言葉だけ、最短で。

SCF
自己無撞着計算。電子密度が自分自身と矛盾しなくなるまで繰り返す、全ての出発点。
NSCF
SCF で得た電荷密度を固定して、別の（普通はもっと密な）k 点で固有値だけ求める計算。DOS やバンドの前段。
ecutwfc
波動関数を展開する平面波のカットオフ。大きいほど正確で遅い。単位 Ry。
ecutrho
電荷密度側のカットオフ。PAW/USPP では ecutwfc の 8 倍が目安。
k 点
逆格子空間のサンプリング点。金属ほど密に要る。8 8 8 は各方向 8 分割。
スメアリング
フェルミ面付近の占有数をぼかして収束を助ける手法。金属には必須。幅が degauss。
PAW / USPP / NC
擬ポテンシャルの種類。PAW と超ソフト（USPP）は低いカットオフで済み、ノルム保存（NC）は素直だが重い。
価電子数 Z_val
その擬ポテンシャルが陽に扱う電子数。バンド数の見積もりに使う。
VBM / CBM
価電子帯上端 / 伝導帯下端。その差がバンドギャップ。
E_F
フェルミ準位。金属では電子が詰まっている高さ。絶縁体ではギャップの中のどこか（計算手法による）。
直接 / 間接
VBM と CBM が同じ k 点にあれば直接ギャップ、違えば間接ギャップ。Si は間接。
PDOS
状態密度を原子・軌道（s, p, d）ごとに分解したもの。どの軌道がどのバンドを作っているか分かる。
vc-relax
セル（格子ベクトル）と原子位置を同時に最適化する計算。relax はセルを固定。
primitive cell
結晶を表現する最小の単位胞。同じ結晶でも取り方が複数あるので、ezcal は標準形に揃える。
高対称線
バンド図の横軸。Γ, X, L のような特別な k 点を結んだ経路で、seekpath が結晶構造から決める。
強磁性 / 反強磁性
磁気モーメントが揃っているのが強磁性、隣り合う副格子で逆を向いて打ち消し合うのが反強磁性。後者は正味の磁化がほぼ 0 になる。
副格子
同じ元素でも磁気モーメントの向きが違うサイトの集まり。ezcal は Ni1, Ni2 というラベルで区別し、pw.x にも別 species として渡す。
磁気単位胞
磁気秩序まで含めて周期性が閉じるセル。反強磁性では化学式上の最小セルより大きくなる。
絶対磁化 |M|
磁気モーメントの大きさをセル全体で積分したもの。反強磁性で正味の磁化が 0 でも、これは 0 にならない。
Bader 電荷
電子密度を「勾配がゼロになる面」で原子ごとの領域に切り分け、その中の電子を数えたもの。基底の取り方に依らないのが利点。
Löwdin 電荷
波動関数を原子軌道に射影して数えた電荷。軌道ごとの内訳が出るが、使う基底に依存する。
cube ファイル
3次元の量（電荷密度など）を格子点上に並べたテキスト形式。VESTA など多くの可視化ソフトが読める。
体積弾性率 B₀
体積を縮めるのに要する固さ。E(V) 曲線の曲率から求める。格子定数と並ぶ、構造記述の標準的な検証量。
N(E_F)
フェルミ準位における状態密度。金属の電子物性（比熱・超伝導など）に直結する量で、DOS の形を数値で比べるのに使う。
d バンド中心
占有 d 状態のエネルギー重心（E_F 基準）。遷移金属の触媒活性の指標としてよく使われる。
DFT+U
遷移金属の d 電子などに補正を入れる手法。--hubbard-u Ni=6.0 のように与える。
